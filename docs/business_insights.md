# Business insights and recommendations (synthetic demonstration)

1. Compare airport shipment/passenger/booking volumes to prioritize operational resources.
2. Examine monthly seasonality before planning capacity or pricing.
3. Investigate underperforming routes, controlling for different volumes and mix.
4. Use airline/airport segment comparisons to identify targeted interventions.
5. Track data quality, definitions and forecast error before trusting executive decisions.

## Suggested actions
Review bottleneck segments; establish monthly KPI reporting; investigate anomalous routes; use controlled tests before changing operations; compare actual outcomes with model estimates. These are hypotheses for demo data, not real airline recommendations.

## Workflow in interview
Generate reproducible source records -> validate and clean -> import SQLite -> query with SQL -> group and visualize in Pandas -> explain KPIs and limitations -> export reports.
